# 💰 React Crypto

A modern cryptocurrency tracking app built with React and TypeScript.  
It allows users to explore crypto market data, manage a personal portfolio, and track performance trends.

👉 **Live Demo:** https://itssonyamisyura.github.io/react-crypto/  
👉 **Repository:** https://github.com/itssonyamisyura/react-crypto  

---

## 🚀 About

This project is a high-performance frontend application that provides a comprehensive overview of the cryptocurrency market. It features a fully responsive design, persistent state management, and a robust type-safe architecture.

The app demonstrates:
- **TypeScript**: Full type safety across the entire codebase.
- **Persistent Storage**: Portfolio data is saved locally using `localStorage`.
- **Responsive UI**: Optimized for Mobile, Tablet, and Desktop.
- **Advanced State Management**: Using React Context for efficient data flow.
- **Data Visualization**: Integrated charts for portfolio distribution.

---

## ✨ Features

- 📊 **Interactive Dashboard**: View real-time cryptocurrency data and rankings.
- 💼 **Portfolio Management**: Add assets and track your total portfolio value.
- 💾 **Persistence**: Your portfolio is saved in your browser and persists across refreshes.
- 📈 **Visual Analytics**: Pie charts for portfolio diversification.
- 🔍 **Global Search**: Quick search for any coin with keyboard shortcuts (`/`).
- 📄 **Deep Insights**: Detailed modals showing price changes (1h, 1d, 1w), market cap, and contract addresses.
- 📱 **Mobile First**: Fully optimized layout for touch devices and small screens.

## 🔧 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/itssonyamisyura/react-crypto.git
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Run the development server:**
   ```bash
   npm run dev
   ```
4. **Build for production:**
   ```bash
   npm run build
   ```
5. **Deploy to GitHub Pages:**
   ```bash
   npm run deploy
   ```
